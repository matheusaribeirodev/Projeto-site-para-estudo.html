# 🦉 MathTrail UNICAMP (Calculando)

> Uma plataforma web gamificada de trilhas de estudo de matemática — inspirada no modelo do Duolingo — desenvolvida por estudantes da **UNICAMP** para tornar o aprendizado de exatas mais interativo, acessível e divertido.

---

## 🎯 Sobre o Projeto

O **MathTrail** nasceu da iniciativa de alunos da UNICAMP com o objetivo de combater a barreira e a evasão em matérias de matemática (tanto no ensino básico quanto em cálculos universitários introdutórios). O sistema transforma conceitos matemáticos densos em "lições rápidas" estilo jogo, divididas em fases, com direito a sistema de vidas, pontos de experiência (XP), ofensivas (*streaks*) e recompensas.

---

## ✨ Funcionalidades Principais

* 🗺️ **Trilhas de Conhecimento:** Módulos progressivos que vão desde a Matemática Básica até o Cálculo Avançado, desbloqueados conforme o progresso do aluno.
* 🔥 **Sistema de Ofensivas (*Streaks*):** Incentiva o hábito de estudo diário através de contadores de dias consecutivos.
* ❤️ **Sistema de Vidas e Recompensa:** Erros custam vidas, exigindo revisões estratégicas dos conceitos antes de avançar.
* ⚡ **Exercícios Rápidos e Dinâmicos:** Questões de múltipla escolha, verdadeiro ou falso, preenchimento de lacunas e resolução rápida de equações.
* 📊 **Painel de Progresso:** Acompanhamento de desempenho por tópico para identificar pontos fortes e fracos.

---

## 🛠️ Tecnologias Utilizadas

Este projeto utiliza uma stack moderna e de fácil execução local:

* **Frontend:** [React](https://react.dev/) / [Next.js](https://nextjs.org/) com Tailwind CSS para uma interface fluida e responsiva.
* **Backend:** [Node.js](https://nodejs.org/) com [Express](https://expressjs.com/) para gerenciamento de rotas e lógica de gamificação.
* **Banco de Dados:** [SQLite](https://www.sqlite.org/) para armazenamento leve de usuários, progresso e banco de questões.
* **Containerização:** [Docker](https://www.docker.com/) para padronizar o ambiente de desenvolvimento.
